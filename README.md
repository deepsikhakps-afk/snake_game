# 🐍 Snake Game

A modern and interactive **Snake Game** built using **HTML, CSS, and JavaScript**. Control the snake using the keyboard, collect food to increase your score, avoid collisions, and beat your highest score. The game also includes multiple speed levels, pause functionality, and persistent high-score storage using Local Storage.

---

## 📌 Features

* 🎮 Classic Snake Game
* ⌨️ Keyboard controls (Arrow Keys & WASD)
* 🍎 Random food generation
* 📊 Live score tracking
* 🏆 High score saved using Local Storage
* ⚡ Multiple speed levels (Slow, Medium, High)
* ⏸️ Pause and resume using the Spacebar
* 💀 Game Over screen with Play Again button
* 🎨 Modern dark-themed user interface
* 📱 Responsive and lightweight design

## 🚀 Getting Started

1. Download or clone this repository.
2. Open the project folder.
3. Double-click **index.html** or open it in your preferred web browser.
4. Start playing and try to beat your high score!

---

## 🎮 How to Play

* Use the **Arrow Keys** or **W, A, S, D** to move the snake.
* Eat the red food to increase your score and grow the snake.
* Avoid hitting the walls.
* Avoid colliding with the snake's own body.
* Press the **Spacebar** to pause or resume the game.
* Click **Play Again** after a game over to restart.

---

## 🎯 Controls

| Key   | Action         |
| ----- | -------------- |
| ↑ / W | Move Up        |
| ↓ / S | Move Down      |
| ← / A | Move Left      |
| → / D | Move Right     |
| Space | Pause / Resume |
